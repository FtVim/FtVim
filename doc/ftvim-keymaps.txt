General

  <C-\>                  n,t    Toggle Terminal
  <C-Down>               n      Decrease Window Height
  <C-H>                  n,t    Go to Left Window
  <C-J>                  n,t    Go to Lower Window
  <C-K>                  n,t    Go to Upper Window
  <C-L>                  n,t    Go to Right Window
  <C-Left>               n      Decrease Window Width
  <C-Right>              n      Increase Window Width
  <C-S>                  n,x,i  Save File
  <C-Up>                 n      Increase Window Height
  <Down>                 n      Move Down
  <Esc>                  n,i    Escape and Clear hlsearch
  <F5>                   n      Run/Continue
  <Left>                 n      Move Left
  <M-j>                  n,x,i  Move Down
  <M-k>                  n,x,i  Move Up
  <Right>                n      Move Right
  <Up>                   n      Move Up
  [[                     n      Prev Reference
  [B                     n      Move Buffer Prev
  [b                     n      Prev Buffer
  [q                     n      Previous Quickfix
  ]]                     n      Next Reference
  ]B                     n      Move Buffer Next
  ]b                     n      Next Buffer
  ]q                     n      Next Quickfix
  a                      x      Around textobject
  al                     x      Around last textobject
  an                     x      Around next textobject
  g[                     n,x    Move to left "around"
  g]                     n,x    Move to right "around"
  gcO                    n      Add Comment Above
  gco                    n      Add Comment Below
  H                      n      Prev Buffer
  i                      x      Inside textobject
  il                     x      Inside last textobject
  in                     x      Inside next textobject
  j                      n,x    Down
  jk                     i      Better Escape
  k                      n,x    Up
  L                      n      Next Buffer
